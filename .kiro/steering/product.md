# BanHops Product Overview

## What is BanHops?

BanHops is a smart transportation app focused on helping travelers navigate routes to Banha, Egypt. The app provides intelligent route planning, real-time transportation options, and AI-powered assistance for commuters.

## Key Features

- **Multi-Modal Route Planning**: Supports train, microbus, and mixed transportation options
- **Smart Route Recommendations**: AI-driven scoring system to recommend optimal routes based on cost, time, and convenience
- **Bilingual Support**: Full English and Arabic localization with automatic RTL (right-to-left) support
- **Trip History**: Track and manage past journeys
- **AI Chat Assistant**: Context-aware chat support for route queries and travel advice
- **Train Lines Visualization**: Interactive railway map showing 6 major train routes to Banha:
  - Cairo/Giza — Benha Line
  - Alexandria/Sidi Gaber — Benha Line
  - Damietta/Mansoura — Benha Line
  - Central Delta & Menoufia — Benha Line
  - Canal & Sharqia — Benha Line
  - Upper Egypt — Benha Line
  - Features zoomable map, live trip finder, and station-by-station route details

## Target Users

Commuters traveling to Banha from various Egyptian cities including Cairo, Alexandria, Tanta, Mansoura, and surrounding areas.

## Core User Flows

1. **Language Selection** → **Sign In/Sign Up** → **Home Screen**
2. **Route Planning**: Enter origin and destination → View route options → Select best match → View detailed step-by-step instructions
3. **Train Lines Exploration**: Browse interactive railway map → Select train line → View stations and route details → Find live trips
4. **History Tracking**: Automatic trip logging with ability to review and clear history
4. **AI Assistance**: Context-aware chat for route questions, real-time updates, and travel tips

## Design Language

- **Primary Color**: #4A90E2 (Blue)
- **Theme**: Light mode throughout, with dark mode only for Route Details screen
- **Style**: Modern, clean UI with Material Design 3
- **Typography**: Roboto font family
